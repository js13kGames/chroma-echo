# CHROMA ECHO — Postmortem Template

## The original idea
The game started with one question:

**What if dying did not erase your progress — what if your previous attempt became a teammate?**

That became CHROMA ECHO.

## What worked
- The Rainbow Echo mechanic immediately communicates the theme.
- The mechanic turns repetition into collaboration.
- Canvas primitives made the visual identity possible without image files.
- Web Audio avoided shipping sound assets.

## What we would improve
- Add more puzzle layouts.
- Improve onboarding for the rewind mechanic.
- Add more visual differentiation between Echo generations.
- Tune level difficulty after external playtests.

## Biggest lesson
The 13KB limit was not merely a technical restriction. It forced the design to focus on one memorable mechanic instead of a large collection of features.
